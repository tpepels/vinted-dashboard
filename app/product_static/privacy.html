PRIVACY

Privacy policy

Scope

This policy covers the Reseller Dashboard web application and its Chrome companion. The Chrome companion has one purpose: synchronize the reseller data needed by a paired workspace from the user's signed-in Vinted account.

Data processed

The dashboard may store account details, master inventory, marketplace listings, orders and purchases, listing views and favourites, follower/following counts, favourite-event metadata, and listing text saved into master inventory. The Chrome companion also stores a revocable dashboard bridge token, pairing information and last-sync status in Chrome local storage.

If the optional photo listing assistant is enabled, product photos are sent to the configured AI analysis provider only after the user explicitly clicks Analyze. Those uploaded photo bytes are used for that analysis request and are not persisted by the dashboard. The resulting detected fields and user-edited listing text are stored only when the user creates the master inventory item.

The Chrome companion does not read or transmit Vinted passwords or raw authentication cookies. It does not collect general browsing history. Its site access is limited to the explicitly listed Vinted origins and the paired dashboard origin.

How data is used

Data is used only to provide and improve the disclosed reseller-workspace functions: inventory synchronization, order tracking, analytics, physical-stock reconciliation, optional user-requested listing-photo analysis, listing preparation, and related reliability/security operations. User data is not sold, used for personalized advertising, or transferred to advertising or data-broker services.

Data sharing and human access

The Chrome companion sends synchronized data only to the dashboard origin with which the user explicitly pairs it. A self-hosted installation is controlled by that installation's operator. For a hosted installation, infrastructure providers may process data only as required to operate the service.

Human access to user data is not allowed except when the user explicitly requests support involving specific data, when required for security or abuse investigation, when required by law, or for aggregated/anonymized operational analysis.

Security and retention

Production Store builds require HTTPS. Dashboard sessions and Chrome bridge credentials are revocable. Connector credentials stored by the dashboard are encrypted at rest when the production encryption key is configured.

Persistent workspace data remains until it is deleted by the user or workspace administrator. Infrastructure logs and backups, if enabled by the deployment operator, follow that deployment's retention configuration.

User controls

Users can disconnect a paired Chrome browser at any time, export workspace data from Settings, and delete a workspace from Settings. Disconnecting removes the bridge token from the extension; deleting a workspace removes its application data from the active database.

Chrome Web Store Limited Use

Use of information received through the Chrome companion adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Access and transmission are limited to data necessary for the extension's disclosed single purpose.

Contact

For a hosted installation, use the privacy/support contact published with that service and its Chrome Web Store listing. For a self-hosted installation, contact the administrator of that deployment.
