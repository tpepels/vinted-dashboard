Chrome sync extension

Use the Vinted session already signed in on this laptop. The extension sends only dashboard data to media-server:5050 - it does not export Vinted cookie values.

Download Chrome extension ZIP
  1. Extract the ZIP somewhere permanent.
  2. Open chrome://extensions, enable Developer mode, then choose Load unpacked.
  3. Select the extracted folder and click Sync now in the extension.
Manual cookie session fallback

If you do not want to use Chrome sync, paste Vinted's signed-in cookies here. For automatic renewal, include both access_token_web and refresh_token_web.
